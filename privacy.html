Português

Dados acessados

Com a autorização do próprio criador, a ferramenta acessa apenas:

  • Informações básicas do perfil do TikTok (ID aberto, nome de exibição e foto), via escopo user.info.basic, para confirmar qual conta está conectada;
  • Permissão de envio de vídeos ao rascunho (video.upload).

Como os dados são usados e guardados

Os tokens de acesso ficam salvos apenas no computador do criador. Nenhum dado é enviado a servidores próprios, vendido, compartilhado com terceiros ou usado para publicidade. Os vídeos vão diretamente do computador do criador para o TikTok.

Dados de outras pessoas

A ferramenta não coleta dados de outros usuários do TikTok.

Remoção

O acesso pode ser revogado a qualquer momento no app do TikTok, em Configurações e privacidade → Segurança → Apps e serviços. Os tokens locais podem ser apagados excluindo os arquivos da ferramenta.

YouTube

A ferramenta usa os Serviços da API do YouTube. Ao usá-la, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Dados acessados: informações e estatísticas do canal do próprio criador, seus vídeos, playlists, legendas e comentários, apenas com autorização via OAuth.

Uso e armazenamento: os dados são usados só para gerenciar o próprio canal e mostrar as estatísticas ao criador. Ficam apenas no computador do criador, não são compartilhados nem vendidos, e dados obtidos da API são apagados ou atualizados em no máximo 30 dias.

Revogação e exclusão: o acesso pode ser revogado a qualquer momento nas configurações de segurança da Conta Google. Ao revogar, os tokens e dados locais são apagados.

English

Data accessed

With the creator's own authorization, the tool only accesses:

  • Basic TikTok profile information (open ID, display name and avatar), via the user.info.basic scope, to confirm which account is connected;
  • Permission to send videos to drafts (video.upload).

How data is used and stored

Access tokens are stored only on the creator's computer. No data is sent to any other server, sold, shared with third parties or used for advertising. Videos go directly from the creator's computer to TikTok.

Other people's data

The tool does not collect data about other TikTok users.

Deletion

Access can be revoked at any time in the TikTok app under Settings and privacy → Security → Apps and services. Local tokens can be removed by deleting the tool's files.

YouTube

This tool uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply.

Data accessed: the creator's own channel information and analytics, videos, playlists, captions and comments, only with OAuth authorization.

Use and storage: data is used only to manage the creator's own channel and show analytics to the creator. It is stored only on the creator's computer, never shared or sold, and data obtained from the API is deleted or refreshed within 30 days.

Revocation and deletion: access can be revoked at any time in the Google Account security settings. When access is revoked, local tokens and data are deleted.
